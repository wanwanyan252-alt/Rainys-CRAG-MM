# CRAG-MM v0.1.2 完整 validation 评测报告

日期：2026-11-23（Asia/Shanghai）

## 1. 结论摘要

本次完成官方 validation 全部 1,938 条推理和 DeepSeek 语义裁判。全量结果为正确 617、弃答 766、错误 555、裁判错误 0、Truthfulness `0.0320`。

真正冻结的盲测区间 200–1937 共 1,738 条：正确 536、弃答 683、错误 519、Truthfulness `0.0098`。该结果显著低于前 100/200 条开发阶段，说明小样本定向优化没有稳定泛化到完整数据集。

## 2. 方法与数据边界

- 数据集：`crag-mm-2025/crag-mm-single-turn-public`，revision `v0.1.2`，validation 全部 1,938 条。
- 0–199 为开发区间；其中 0–99 含一轮参考答案辅助的定向修复，不能视为纯盲测。
- 200–1937 在冻结 Llama、检索、提示词和后处理策略后一次性运行，作为主要泛化结果。
- 模型：Llama 3.2 11B Vision Instruct；检索：官方图片索引与 1,681,350 条网页索引。
- 裁判：DeepSeek `deepseek-flash`；这是对照裁判，不是官方 `gpt-4o` 成绩。
- 515 张仅含 URL 的公开 Wikimedia 图片使用官方 1280px 缩略图；其余 egocentric 图片按评测流程使用 960×1280。

## 5. 证据审计消融实验

在开发区间 100–199 上，DeepSeek 只读取问题、识别实体、检索证据和候选回答，不读取参考答案，执行严格证据审计。

原已回答样本包含正确 32、错误 23；审计仅保留 15 条，其中正确 14、错误 1，保留答案精度 `93.33%`。

该审计能显著降低错误，但正确答案保留率过低，因此只作为高精度安全模式消融，未进入全量主线。

## 6. 失败结论与项目价值

- 当前系统在小样本上可通过定向修复达到较好 Truthfulness，但在 1,738 条冻结盲测上接近零净得分，说明主要瓶颈是图像实体解析与检索证据串线，而不是简单的回答格式问题。
- 全量结果不应再通过逐条参考答案修补来提高主指标；后续改进应更换或增强视觉实体模型、OCR、跨裁剪一致性和证据蕴含验证，并在新的留出集上验证。
- 本项目的含金量来自完整数据覆盖、开发/盲测隔离、可断点复现、完整失败分布和诚实报告，而不是只展示经过人工修复的前 100 条高分。
